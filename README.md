# AI 合规评估应用（中国法域 · 推荐算法 / 生成式人工智能 / 大模型）

一个**完全本地运行、单 HTML 文件**的合规风险评估工具，面向中国法域，覆盖三大场景：

- **推荐算法合规**（依据《互联网信息服务算法推荐管理规定》）
- **生成式人工智能（AIGC）合规**（依据《生成式人工智能服务管理暂行办法》及 TC260 系列要求）
- **大模型合规与备案**（含深度合成、生成内容标识专项，依据 GB/T 45652 / 45654 / 45674-2025 等）

> 无需联网、无需后端服务器、无需安装任何依赖。双击 `AI合规评估应用.html` 即可在任意现代浏览器中使用。

---

## ✨ 功能特性

- **向导式评估**：项目信息 → 适用范围与模块 → 合规问卷 → 风险评估 → 整改跟踪 → 证据链 → 评估报告。
- **问答 + 勾选 + 上传证据**：每题四档自评（已执行 / 执行不充分 / 未执行 / 不适用），逐题可上传证明材料。
- **条件触发**：按产品场景（是否面向未成年人、是否具舆论属性、是否处理个人信息、是否涉深度合成 / 生物识别编辑、是否提供大模型等）自动隐藏不适用题目。
- **风险自动识别**：实时计算高 / 中 / 低 / 合规 / 不适用风险等级与综合评级，定位法规依据。
- **整改建议**：每个风险项自动给出针对性整改建议。
- **整改跟踪**：一键生成跟踪项，维护状态 / 责任人 / 时限 / 说明，本地持久化。
- **证据链**：评估过程与上传材料按问题归集，可逐项下载核验，形成完整证据链条。
- **本地持久化**：基于浏览器的 IndexedDB 保存全部项目、作答、证据与跟踪项；支持多项目切换。
- **导出**：
  - **PDF**：浏览器「打印 → 另存为 PDF」。
  - **DOCX**：纯 JavaScript 生成（`OOXML` + `ZIP`，无第三方库），可直接用 Word / WPS 编辑。

## 🚀 快速开始

1. 用浏览器打开 `AI合规评估应用.html`（推荐 Chrome / Edge / Firefox）。
2. 在「项目信息」填写被评估对象基本信息。
3. 在「适用范围与模块」勾选涉及的业务模块与场景，系统据此裁剪问卷。
4. 在「合规问卷」逐题作答，按需上传证明材料。
5. 在「风险评估」查看风险分布与整改建议；「整改跟踪」维护闭环。
6. 「评估报告」页可刷新预览并导出 PDF / DOCX。

> 首次打开会自动创建一个示例项目，数据仅保存在你本机浏览器中。

---

## 🔒 隐私与数据说明

- 本应用**不发起任何网络请求**，所有评估数据与上传的证据文件均存储于本地浏览器（IndexedDB）。
- 更换浏览器 / 清除站点数据会丢失本地记录，请重要项目及时导出 PDF / DOCX 备份。
