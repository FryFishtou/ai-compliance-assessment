## 四、AI 合规专题解读（29 篇 .doc）

定义与基础：生成式人工智能的定义；AI 训练数据的法律与伦理规范；AI 数据泄露的后果。

个人信息处理：敏感个人信息处理（AI 模型训练）；数据最小化原则；数据保护影响评估（DPIA）；目的限制原则；知情权与决定权；数据来源合规要求（含使用用户公开数据训练）；数据保留与删除。

AIGC 与深度合成：向公众提供 AIGC 的界定；AIGC 服务供应商资质；AIGC 与深度合成技术的区别；深度合成服务提供者与使用者的区分；深度合成技术的认定；深度合成技术与算法推荐技术的区别；虚拟数字人法律问题。

数据与模型治理：数据标注（国际标准与流程）；算法歧视及其避免；数据处理协议（DPA）制定；大模型备案要求；APP / 小程序接入大模型的披露。

算法推荐专题：算法推荐的定义；算法推荐与自动化决策的关系；针对设备 ID 的内容推荐是否属个性化推荐；地理位置是否算用户标签；舆论属性与社会动员能力的认定；算法推荐监管是否适用于 To B 场景。
